# 蓝牙音乐连接性能测试报告

## 1. 测试目标

- 快速连接：从点击搜索到的蓝牙设备“连接”按钮开始，到系统确认 A2DP/A2DP Sink 音频链路连接成功，目标耗时 <= 5 秒。
- 连接稳定性：正常使用环境下，设备距离 <= 10 米、无强电磁干扰，连接中断率 < 0.5%，单次连续使用时间不低于 2 小时。
- 功能保持：优化仅作用于蓝牙音乐连接链路，不改变本地音乐、收音机、U 盘音乐等现有模块能力。

## 2. 本次代码侧优化

- 发起连接前立即取消蓝牙搜索，减少 discovery 对连接建立的抢占。
- 连接请求进入 5 秒快连窗口，原生侧以 450ms 间隔快速确认 A2DP/A2DP Sink 状态。
- 前端连接确认窗口从 30 秒收敛到 5 秒，并在 5 秒内高频刷新设备状态。
- 增加原生连接指标采集：
  - `targetFastConnectMs`
  - `lastElapsedMs`
  - `successCount`
  - `failureCount`
  - `disconnectCount`
  - `currentSessionMs`
  - `totalConnectedDurationMs`
  - `samples`
- 新增 JS Bridge：`MusicBridge.getBluetoothConnectionMetrics()`，用于实机测试时导出连接耗时和稳定性样本。

## 4. 数据采集方式

1. 打开蓝牙音乐模块，点击“搜索设备”。
2. 点击目标设备“连接”。
3. 连接成功或失败后，通过 WebView/调试通道读取：

```js
MusicBridge.getBluetoothConnectionMetrics()
```

4. 记录返回 JSON 中的 `lastElapsedMs`、`lastResult`、`disconnectCount`、`currentSessionMs` 和 `samples`。
5. 稳定性测试持续播放 2 小时，结束后读取 `disconnectCount` 和 `totalConnectedDurationMs`。
