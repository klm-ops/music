# 收音机功能测试报告

## 测试范围

- 频道搜索：自动搜索、向上搜台、向下搜台。
- 频率调节：FM `87.5-108.0 MHz`，AM `520-1710 kHz`。
- 频道存储：当前频率写入当前记忆位。
- 电台收藏：收藏/取消收藏、收藏列表过滤。
- 播放控制：播放、暂停、上一台、下一台。
- 音量控制：滑块、音量加、音量减、静音/取消静音。
- 模块隔离：切换到本地音乐或蓝牙音乐时暂停收音机音频。

## 验证结果

| 功能 | 结果 |
| --- | --- |
| FM/AM 模式切换 | 通过，频率范围、单位、列表同步更新 |
| 自动搜索 | 通过，按当前模式更新电台列表 |
| 手动搜台 | 通过，支持左右键和按钮调频 |
| 存台 | 通过，当前频率写入当前预设位 |
| 收藏 | 通过，数据持久化到 `localStorage` |
| 播放/暂停 | 通过，Web Audio 正常启停 |
| 音量调节 | 通过，滑块、步进按钮、静音状态同步 |
| 模块切换 | 通过，切走收音机时停止收音机音频 |

## 构建验证

- Android Debug 构建通过。
- 输出 APK：`app/build/outputs/apk/debug/app-debug.apk`

## 说明

普通 Android WebView 应用通常无法直接访问设备 FM 射频芯片；当前实现为应用内 FM/AM 收音机交互模型与本地 Web Audio 声音输出，保证在 Android WebView 内稳定运行。
