# 收音机用户体验评估

## 响应速度

- 按钮交互仅更新当前收音机模块 DOM，未触发跨模块重绘。
- 自动搜索使用短延迟模拟搜台过程，常规按钮反馈在 300ms 内完成。
- 播放/暂停使用现有 Web Audio 节点，避免重复创建导致卡顿。

## 触控体验

- FM/AM、搜索、存台、收藏、播放、音量按钮可点击区域均不低于 44px。
- 当前选中电台、收藏状态、静音状态均有明确文本或颜色反馈。
- 键盘方向键仍可执行调频和音量调节，保留桌面调试体验。

## 可视性

- 收音机界面使用纯黑背景和白/灰文本，适合不同亮度环境。
- 当前频率居中放大显示，单位、信号强度与电台列表信息分区明确。
- 移除卡片阴影、渐变和纹理，降低视觉层级干扰。

## 兼容性

- 仅收音机模块启用纯黑布局覆盖，不影响本地音乐和蓝牙音乐。
- 平板、桌面、移动端均保持收音机单屏居中布局。
- 已同步 Web 资源到 Android assets，用于 APK 内 WebView 加载。
